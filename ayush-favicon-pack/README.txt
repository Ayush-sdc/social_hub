AYUSH FAVICON PACK

Original geometric A monogram with particle-network accents.
Colors: green #28cc29, background #182428.
Small 16px and 32px PNGs omit fine accents for clarity.

INSTALL
Copy icon files and site.webmanifest beside your website index.html.
Replace existing favicon tags with head-tags.html contents.
Relative paths support GitHub Pages /social_hub/.
Keep only one theme-color meta tag.
Commit and push these files to GitHub. Favicons may require a hard refresh or a new browser tab due to caching.

Includes SVG, multi-size ICO, PNGs, Apple touch icon, Android icons,
maskable icon, and a transparent-corner 1024px logo.
The manifest supplies icons and launch metadata; it does not add offline support.
